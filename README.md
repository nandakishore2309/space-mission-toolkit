
# 🚀 Space Mission & Orbital Mechanics Toolkit in C

A menu-driven scientific computing application developed in C to explore orbital mechanics, planetary science, spacecraft engineering, and gravitational physics.

The project aims to bring fundamental space science and engineering calculations into one interactive command-line toolkit.

## 🌌 Project Overview

The Space Mission & Orbital Mechanics Toolkit is an educational software project designed to perform scientific calculations related to space missions and celestial bodies.

It combines mathematical concepts, classical physics, and fundamental aerospace engineering principles into a single application.

## 🎯 Objectives

- Understand the mathematical foundations of orbital mechanics.
- Perform calculations related to spacecraft motion and propulsion.
- Explore physical properties of planets and moons.
- Study gravitational phenomena using mathematical models.
- Develop problem-solving and programming skills using C.
- Build a foundation for future aerospace and space technology projects.

## 📐 Scientific Concepts

The project uses fundamental equations from physics and aerospace engineering.

| Concept                        | Equation                  |
| ------------------------------ | ------------------------- |
| Orbital Velocity               | v = √(μ/r)                |
| Orbital Period                 | T = 2π√(a³/μ)             |
| Escape Velocity                | v = √(2μ/r)               |
| Gravitational Force            | F = GMm/r²                |
| Rocket Equation                | Δv = Isp × g₀ × ln(m₀/mf) |
| Schwarzschild Radius           | rs = 2GM/c²               |
| Gravitational Potential Energy | U = -GMm/r                |

All calculations will use consistent SI units internally wherever possible.

## 🚀 How to Run

### Requirements

- GCC or Clang compiler
- C development environment
- Windows, Linux, or macOS

### Compile

Using GCC:

```bash
gcc main.c -o space_toolkit -lm
```

### Execute

Windows:

```bash
space_toolkit.exe
```

Linux:

```bash
./space_toolkit
```
